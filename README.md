# Vikas B — Full Stack Developer Portfolio

An interactive, single-page portfolio for **Vikas B**, a freelance web developer based in Coimbatore, Tamil Nadu. The site introduces Vikas, highlights selected projects and skills, and provides contact links for collaboration.

## About

Vikas is an Electrical and Electronics Engineering graduate who has been building web applications as a freelancer since 2024. The portfolio highlights experience with React, Node.js, Python, MySQL, and a range of web and software projects.

## Run Locally

This is a static site; no build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/vikas-040304/Vikas-Full-Stack-Developer-Portfolio-.git
   cd Vikas-Full-Stack-Developer-Portfolio-
   ```
2. Start a local web server:
   ```bash
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000/Vikas%20B%20%E2%80%94%20Full%20Stack%20Developer.html` in your browser.

Alternatively, open `Vikas B — Full Stack Developer.html` directly in a modern browser. An internet connection is needed to load the GSAP libraries from the CDN.
