# Vikas B — Full Stack Developer Portfolio

A personal portfolio website showcasing my skills, projects, and professional profile as a Full Stack Developer.

## Overview

This repository contains a responsive single-page portfolio built with HTML, CSS, and JavaScript. It presents:

- Professional profile and introduction
- Skills and technology stack
- Project highlights
- Experience and expertise overview
- Contact details and social links

## Project Structure

- `Vikas B — Full Stack Developer.html` — main portfolio webpage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive web design

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/vikas-040304/Vikas-Full-Stack-Developer-Portfolio-.git
   ```
2. Open the HTML file directly in a browser, or serve it locally:
   ```bash
   cd Vikas-Full-Stack-Developer-Portfolio-
   python3 -m http.server 8000
   ```
3. Visit:
   ```text
   http://localhost:8000/
   ```
